# software-trenazer
Práca sa zaoberá návrhom a implementáciou softvérového systému pre inteligentný trenažér. Cieľom práce je vytvoriť ucelený systém umožňujúci zber, spracovanie a prehľadnú vizualizáciu prevádzkových parametrov jazdy v reálnom čase. Hlavnou riadiacou jednotkou systému je platforma Raspberry Pi
